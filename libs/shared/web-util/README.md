# shared-web-util

TypeScript sem framework para os apps do front (ADR 027), importado por `@marketplace/shared-web-util`: moeda pelo `Intl` em pt-BR (`formatMoney`), datas no fuso `America/Sao_Paulo` (`formatDateTime`, `formatShortDateTime`, `formatRelative`), conversão do `datetime-local` lido em São Paulo para o instante UTC (`fromDateTimeLocal` e `toDateTimeLocal`, ADR 028), texto dos motivos de recusa (`translateReason`, que usa a sobrescrita do front, a `message` de `reasonDetails`, o `detail` e o `title` do problema, nesta ordem, e nunca mostra o código cru), helpers do problema RFC 9457 (`toProblem`, `problemMessages`, `problemReasons`, `fieldErrors`, `isEditConflict`, `fieldPath`) e do cliente gerado (`apiData`, e `apiDataWithVersion`, que devolve também a versão para o `If-Match`: a `version` do corpo ou, sem ela, o `ETag` forte da resposta, nunca o fraco que um proxy com gzip entrega; `versionTag` monta o ETag da `version` que vem no corpo), pilha de cursores da paginação (`CursorTrail`), ordem das listas (`parseSort`), ações calculadas pelo servidor (`actionState` e `allowsAction`, sobre `actions` e `blockedActions`), limites dos formulários lidos dos JSON Schemas do contrato (`fieldRules`, `checkFieldRules` e `ruleMessage`) e os lotes (`runBatch`, que envia os grupos um por vez e separa gravados, recusados e sem resposta, `batchRunCounts` e `batchSummary`). Os testes rodam com `npx nx test shared-web-util`.
